# Ревью бесплатного доступа

Ревью выполнено по затронутому коду и связанным механизмам Grace Access, панели и ноды.
Это не аудит всех подсистем проекта. Изменения проверены локально; VPS использован только
для чтения исходников, Git-истории, версий и списка контейнеров.

## Исправленные риски

| Сценарий | Итоговое поведение и проверка |
|---|---|
| Любой `EXPIRED` сохраняется на платных нодах | Общее исключение удалено. Только бот переводит допущенную подписку в `ACTIVE` с отдельным бесплатным squad. |
| Общий UUID из вставленной VLESS-ссылки | Импорт сохраняет параметры Host, отбрасывает credential. Ноде и клиенту передаётся личный UUID пользователя. |
| Бесплатный squad содержит платные inbounds | Выдача и импорт требуют ровно inbound выбранного Host. Старые платные ссылки теряют доступ. |
| Позднее REMOVE после назначения бесплатного доступа | Очередь блокирует пару node/user в PostgreSQL и перечитывает состояние. Подтверждено тестом, включая коллизии тегов разных профилей. |
| Бесплатная квота закрывается, а платные группы возвращаются до `EXPIRED` | Сначала очищается доступ к inbounds, дата закрытия фиксируется, повторная попытка её не продлевает. Группы восстанавливаются после `EXPIRED`. |
| Повторная выдача через кнопку/перезапуск | Существующие блокировки и уникальный incident key сохраняют одну выдачу на истечение. Пройден тест повторной выдачи после расходования. |
| Сброс счётчика пополняет бесплатную квоту | `NO_RESET`, без reset на старте; уменьшение счётчика и новый `lastTrafficResetAt` завершают выдачу. Проверены ненулевой и нулевой исходный расход. |
| Перезапись метаданных администратора | `PUT /api/metadata/user/{id}` принимает необязательный `expectedMetadata`. JSONB compare-and-swap сохраняет изменения или возвращает HTTP 409. Старые вызовы PUT совместимы. |
| Чужой subscription_id в кабинете | Новые GET/POST используют существующую выборку с `subscription.user_id == current_user.id`. Негативные проверки обоих endpoints проходят; выдача не вызывается. |
| Административный DISABLED | Выдача не активирует пользователя. Ручная блокировка не отменяется worker. |
| Ошибка/неверная привязка Host | Не выдаётся конфиг на произвольную ноду. Проверяются squad, VLESS, profile, активный inbound, видимость и доступность. Accessible nodes возвращают **теги** inbounds, что учтено в коде и тесте. |
| Потеря истории при миграции | 0132 сохраняет записи/индексы и SQLite delete guard. Downgrade с квотными сессиями отклоняется. |
| Ошибка HTTP ноды теряется в очереди | Ошибка пробрасывается для BullMQ retry, включая `success=false` у добавления. Удаление отсутствующего пользователя остаётся идемпотентным. |

Публичные серверные новости сохранены: выдаются только опубликованные записи;
обновление счётчика просмотров для анонимного запроса пропускается. Авторизация
административных методов не менялась. Префикс nginx uploads ограничен `/uploads/`,
согласован с alias; существующий volume и static files сохранены.

## Целесообразность

Переиспользованы Grace Access sessions/locks/reconciliation, личный пользователь панели,
Internal Squads, selectedHosts metadata, штатные генераторы подписок и существующая
инструкция подключения кабинета. Нет второго VLESS UUID, отдельной таблицы бесплатных
пользователей, второго платёжного контура или изменений Remnanode.

Сохранено различие между оплатой и техническим доступом: оплаченные дата/тариф/squads
хранятся в Bedolaga, а панель получает ограниченный overlay. При оплате используются
свежие данные биллинга. Изменения не списывают баланс и не создают платёж.

Проверка общего Host для действующих выдач кешируется на 30 секунд (до 128 ключей),
чтобы не повторять одинаковые запросы на каждого подписчика. Перед новой выдачей
кеш не используется. Статус пользователя и расход читаются отдельно.

## Что требуется проверить при развёртывании

Не запускались миграция на живой PostgreSQL, SQL CAS/advisory locks под конкурентной
нагрузкой и реальное подключение Xray. Docker Engine на ПК недоступен, а изменять VPS
при этой работе запрещено. SQLite и тестовые двойники не заменяют эти проверки.

Панель/backend-контракты/frontend/бот необходимо обновлять согласованно. Старый backend
не поддерживает `expectedMetadata`; штатный публичный frontend не содержит нового импорта.
После замены старого backend перезапустите ноды, чтобы убрать UUID, сохранённые прежним
общим исключением для `EXPIRED`.

Квота ограничивается счётчиком панели: возможен перерасход на интервал сбора трафика.
Это существующее свойство Remnawave, а не побайтовое ограничение Xray. Техническая дата
2099 видна в заголовках панели; оплаченная дата и остаток квоты показаны в кабинете отдельно.
Существующие sessions/worker обеспечивают повторные попытки при сбоях API. Ошибки
конфигурации не превращаются в общий бесплатный доступ.
